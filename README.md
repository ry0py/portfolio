# portfolio

堀江諒のポートフォリオサイト。HTML / CSS / JavaScript のみで構築した静的サイトです。

公開URL: https://ry0py.com/portfolio/

## 構成

- `index.html` — ホーム（自己紹介・これまでの活動・受賞履歴・学歴）
- `robot-contest/` — ロボットコンテスト
  - `nhk-robocon/` — NHK学生ロボコン
  - `catchrobo/` — キャチロボコンテスト
- `projects/` — 個人製作
- `internship/` — 長期インターン
- `style.css` / `script.js` — 全ページ共通
- `images/` — 画像

## 公開方法

GitHub Pages で公開しています。ユーザーサイト `ry0py.github.io` にカスタムドメイン `ry0py.com` が設定されているため、このリポジトリの Pages は `ry0py.com/portfolio/` で配信されます。
