VRゲーム じゃんけんゲーム からだで操るロボット 無線制御ペンライト

VRゲーム

概要

  • MetaQuest3を使用した射的ゲームを製作しました。作品は2024年度の東京科学大学の学園祭で展示
    • 2日間で合計100人ほどの方にプレイしていただいた
  • リピート率を向上させるために「上振れ」要素としてランダムでスコアの高い的が出るように設定
  • 写真の見栄えを考慮して銃型のアタッチメントを作成

使用ツール

  • Unityを使用したゲーム作成
  • Fusionを使用したアタッチメントの作成

制作年

  • 2024年9月～10月

じゃんけんゲーム

概要

  • グー・チョキ・パーの形をカメラで認識することでロボットが絶対に負ける手を出す
  • 物体検出で手の形を認識してロボットに対応した手の形になるような制御を担当
  • 実際にロボットとじゃんけんをしてる演出のために友人にハードウェアの作成を依頼

使用ツール

  • Python
  • Yolov8を使用した物体検出
  • Tkinterを使用したGUI制作
  • FastLabelを使用したアノテーション
  • Arudinoを使用したロボット制御

制作年

  • 2023年9月～10月

  • 制作したリポジトリ

からだで操るロボット

概要

  • 人間の動きとリンクさせて2足歩行ロボットを動かす作品
  • モーションキャプチャの「Mocopi」で得られた関節位置から2足歩行ロボットのサーボモーターの角度を計算

使用ツール

  • Pythonを用いたロボット制御とUnityとの通信
  • Unityを用いて公式のスマホアプリからの骨格位置を取得

制作年

  • 2025年9月～10月

関連ＵＲＬ

  • ロボットを動かすリポジトリ
  • Mocopiのデータを取得するリポジトリ

無線制御ペンライト

概要

  • BLE(Bluetooth Low Energy)を使用して無線で光の色を制御できるペンライトを製作
  • 単三電池1本で動作できること、持ち手の部分に合うようなサイズとなるように基板を自作

使用ツール

  • KiCadを使用して基板を製作
  • Fusionを使用してペンライトを製作
  • ESPを2つ使用したLEDの制御とBLE機能の実装

制作年

  • 2025年11月～12月
